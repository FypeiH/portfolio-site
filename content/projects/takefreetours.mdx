## Context & problem

TakeFreeTours runs tours across the country, and every tour needs a team of guides. Putting those teams together meant checking each guide's availability for each tour.

## What I built

I worked on both sides of the tour management system: the Angular frontend (TypeScript, HTML and CSS) and a REST API built entirely in .NET (C#). The app manages the tours, the team assigned to each one and every guide's availability. It was my first Angular project.
