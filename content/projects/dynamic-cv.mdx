## Context & problem

Dynamic CV is the web app I use to customize my resume. It shows changes in a real-time preview, switches between Portuguese and English, and exports an A4 PDF in one click. I've kept it updated since April 2025.

## Constraints

- **One page, print-ready.** The output has to fit a single A4 page and print cleanly, while also working as a responsive web page.
- **Easy to update, in two languages.** Changing a job or a skill shouldn't mean editing layout code, and the Portuguese and English versions have to stay in sync.

## Architecture

<Diagram />

It's an Angular 18 app built from reusable components: `app-personal-info`, `app-professional-info`, `app-experience-item` and `app-skill-item`. The content lives in JSON files, and ngx-translate supplies the Portuguese and English text. Tailwind CSS handles the A4 layout. For export, html-to-image turns the rendered page into an image, and jsPDF scales it to A4 and writes the PDF.

## Decisions & trade-offs

- **Client-side PDF export.** html-to-image and jsPDF generate the PDF in the browser, so the app needs no server. `{{TODO: the trade-off Filipe observed (e.g. an image-based PDF means the text isn't selectable or searchable, or file size), only if true (Q-DCV)}}`
- **Data separate from layout.** Content sits in JSON and translation files, so updating the CV never touches a component, and both languages share one layout.
- **Reusable components per CV block.** Experience and skill entries are rendered from one component each, so adding an entry is a data change, not a template change.
